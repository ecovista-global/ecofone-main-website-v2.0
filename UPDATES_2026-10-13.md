## 1. Resume Upload Experience ("Upload from Drive / Device")

### Problem Solved:
Previously, the Careers application forms only accepted a raw Google Drive URL string (`https://drive.google.com/file/d/...`), requiring candidates to manually copy sharing permissions and paste text links.

### What Was Implemented:
1. **Interactive Dual-Mode CV Attachment**:
   - **Mode 1 (Default): "Upload File / Drive"**:
     - Interactive dashed drop-zone supporting PDF, DOC, DOCX up to 10MB.
     - On mobile and desktop, opening the file picker enables direct selection from **Google Drive**, **Local Storage**, **Files**, or **Downloads**.
     - Real-time uploading state with animated spinner and status feedback.
     - Once uploaded, displays an emerald success card with file icon, filename, file size, "Uploaded ✓" badge, and a "Change" button.
   - **Mode 2: "Google Drive Link"**:
     - Retains seamless fallback toggle for candidates who prefer pasting their Google Drive link directly.
     - Helper guidance for view permissions: *"Please ensure your Google Drive link permission is set to: Anyone with the link can view"*.
2. **Dedicated Resume Upload Endpoint (`/api/careers/upload`)**:
   - Accepts multipart/form-data with size validation (<=10MB) and format filtering (`.pdf`, `.doc`, `.docx`).
   - Securely stores uploaded resumes in `public/uploads/resumes/` with sanitized timestamped filenames.
   - Returns public access URL and file metadata (`fileName`, `fileSize`).
3. **Automatic Email Attachment to HR (`future@ecofone.co.in`)**:
   - In `/api/careers/applications`, if a candidate uploads their CV directly, the file is automatically attached to Nodemailer's `attachments` array.
   - EcoFone HR / Talent Acquisition team receives the actual CV file directly in their email inbox, along with candidate details and Google Drive link fallback.
4. **Synchronized Across Both Entry Points**:
   - Enabled in the inline **General Application Section** (`#general-application`).
   - Enabled in the **Job Application Modal** (`handleOpenApplyModal`).
