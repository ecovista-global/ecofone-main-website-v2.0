## Store Locator Redesign & Full Admin Panel CMS (`/` Homepage & `/admin`)

### Overview
Completely overhauled the Store Locator section on the homepage to match the user's reference mockup with 3-in-a-row store cards, address, timings, and action buttons. Removed separate page navigation so stores are experienced directly on the landing page, and created a complete Store Management dashboard in the Admin Panel to manage storefront photos, addresses, phone numbers, timings, Google Maps links, and Open/Closed status.

### Features & Implementation:
1. **Homepage Store Locator Redesign (`store-locator-section.tsx`)**:
   - **Header**:
     - `OUR STORES` green pill badge.
     - Headline: `Find an <span className="text-[#ea580c]">EcoFone Store</span> Near You`.
     - Subtitle: *"Visit our nearest EcoFone store to explore the latest smartphones, accessories and more."*
     - Inline controls: `View all stores →` (toggles all stores grid directly on the page without redirecting) + `<` `>` circular carousel navigation buttons.
   - **Card Design (3 Outlets in a row)**:
     - Top Storefront photo with floating `● Open Now` (emerald) / `● Closed` (rose) badge.
     - Store Name with external Google Maps icon `↗`.
     - **Address**: Green pin + bold label + full address string.
     - **Timings**: Orange clock + bold label + operational hours (e.g. `10:00 AM - 10:00 PM`).
     - Bottom Action Bar: `📞 Call Store` (`tel:...`) and `📍 Get Directions` (direct Google Maps link).
   - **Zero Separate Page Linking**:
     - Removed external page redirects. Stores display immediately on the homepage.
     - `/stores` URL seamlessly redirects to `/#stores-section`.

2. **Admin Panel Store Management (`frontend/app/admin/components/stores-manager.tsx`)**:
   - Integrated into the Admin Panel's `stores` tab.
   - **Live Outlets List**: Card view with live image preview, address, timings, contact phone, and Google Maps link.
   - **One-Click Status Toggle**: Easily switch store between `🟢 Open Now` and `🔴 Closed`.
   - **Add Store Modal**:
     - Store Name, Area / Locality, City.
     - Complete Address.
     - Contact Phone Number.
     - Store Timings.
     - Storefront Image URL or direct file upload (`/api/stores/upload`).
     - Quick preset buttons (`Hazratganj Storefront`, `Alambagh Storefront`, `Gomti Nagar Storefront`).
     - Google Maps URL (or auto-generates from address).
   - **Edit Store Modal**: Edit any existing store's details and photos.
   - **Delete Store**: Instant removal with confirmation dialog.

3. **Persistent Server-Side Storage & API**:
   - `frontend/data/stores.json`: File-based persistent storage.
   - `frontend/app/api/stores/route.ts`: Supports `GET`, `POST`, `PUT`, `DELETE`.
   - `frontend/app/api/stores/upload/route.ts`: Stores uploaded store photos in `/public/uploads/stores/`.
   - Synchronized with `frontend/lib/api.ts`.
